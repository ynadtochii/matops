# Payment providers for gym payments

Checked official provider documents on 2026-09-28. MatOps plans to sell software globally, starting with Portuguese gyms. A student's in-person class or gym membership must be charged by the gym as merchant, not by MatOps. The [gym-owned Stripe design](../stripe-gym-payments-design.md) (updated 2026-10-12) covers card memberships through Stripe Billing, class packs and a provider import, on the gym's own Stripe account, connected through Connect OAuth. The build order is in the [first release slices](../stripe-one-time-payments.md). Merchant countries matter separately from buyer countries: a Portuguese gym accepting foreign cards does not prove a provider can onboard a gym abroad.

Prices below are published Portugal merchant examples, not all-in partner offers. Card type, buyer country, currency conversion, refunds, disputes, tax, subscriptions and partner terms can change the total.

[Square does not list Portugal](https://developer.squareup.com/docs/international-development) as a seller payment country. [Braintree Marketplace](https://developer.paypal.com/braintree/articles/guides/braintree-marketplace/overview) requires US-based master and sub-merchants and does not support recurring billing. [Paddle](https://www.paddle.com/help/start/intro-to-paddle/what-am-i-not-allowed-to-sell-on-paddle) and [Lemon Squeezy](https://docs.lemonsqueezy.com/help/getting-started/prohibited-products) sell as resellers and exclude this gym-service marketplace use case. They are not candidates for student-to-gym payments.

**App rule:** [Apple guideline 3.1.3(e)](https://developer.apple.com/app-store/review/guidelines/) requires non-IAP payment for physical services consumed outside the app. [Google Play](https://support.google.com/googleplay/android-developer/answer/9858738?hl=en) explicitly excludes gym memberships from Play Billing. Next.js and Expo can start a gym-hosted browser checkout for in-person classes; paid digital features need a new policy check. Provider webhooks, not the browser return URL, establish payment success.

**Comparison conclusion:** Stripe remains the best documented fit for gym-owned charges; Mollie is the closest alternative for later subscriptions if calendar retry behavior can be accepted or resolved. This comparison does not set implementation scope. The [Stripe design](../stripe-gym-payments-design.md) sets the scope: card memberships, class packs and a provider import. For later markets, verify gym merchant country support, fee terms, refunds, disputes and account ownership before expansion.

matops

Brand & design system · locked

A grappling gym runs on a schedule, a roster, and a clock.

matops is the instrument that runs all three. Sharp, not loud — monochrome by default, with one signature spark: violet. This is the locked system — the tokens, the mark, and the rules, on real screens.

accent · violet neutrals · warm stone type · Geist + mono clock radius · tight 0.2rem shared tokens · web + mobile
01

The signature — matops violet

The one non-neutral hue that says "matops". Locked. Everything else stays greyscale.

Why violet, specifically: the system already spends blue, orange, red and green on meaning (info / warning / error / success). A brand hue has to sit in the gap so it never gets mistaken for a status. Violet fills that gap — and it's the purple belt, a real grappling milestone. Calm, premium, an instrument. No gradients, one flat tone.
